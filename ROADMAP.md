# Roadmap

## Kubernetes Support

### Done
- [x] List pods
- [x] Create pod
- [x] Delete pod
- [x] Exec in pod (buffered JSON)
- [x] Kube pod event streaming (via shared /events/ws)
- [x] Exec in pod (WebSocket streaming)

### Planned
- [ ] Read file from pod
- [ ] Write file to pod
- [ ] Kube metrics polling (Metrics Server API)
- [ ] Pod logs streaming (WebSocket)
- [ ] Health check endpoint (`/healthz`) reporting backend availability
