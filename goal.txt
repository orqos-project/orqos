RawPair native host MVP

The canonical goal is ../rawpair/goal.txt. Read it together with ../rawpair/docs/HANDOFF.md and docs/HOST_BACKEND.md before implementing.

Work in RawPair and Orqos. Orqos owns the native Linux execution backend: systemd supervision, workspace identities, resource limits, network namespaces, safe files, protected terminal/application forwarding, and runtime status. Preserve its existing Docker/Kubernetes contracts.

Completion requires the real integrated MVP and usable operator setup defined in RawPair's goal. Builds, automated tests, CI, live checks, deployment, and user acceptance are best-effort evidence, not completion gates. The user will build, deploy locally, and use it afterward. Missing core implementation is still unfinished work.

The user handles commits, pushes, and merges.
